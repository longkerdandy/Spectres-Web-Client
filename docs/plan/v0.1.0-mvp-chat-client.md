## 2. Context

Spectres-Web-Client is the first Client-layer project for the Spectres personal assistant. The Runtime (`../Spectres-Runtime`) exposes the Master Agent through an AG-UI endpoint (`POST /agui`, SSE). This milestone delivers the MVP frontend; Runtime-side CORS support lands in Runtime v0.3.0.

Key constraints and decisions:

- **MVP topology assumption**: Web Client and Runtime run on the **same PC**; the browser is on that PC too. No Tailscale, no remote access, no cloud anything in this milestone.
- **Independent app**: the client serves its own static files (dev: Vite dev server; MVP "production": any static file server over `dist/`) and calls the Runtime **cross-origin**. The Runtime does not host the client. CORS is handled Runtime-side (Runtime v0.3.0).
- **Protocol**: AG-UI only, via a direct connection — no CopilotKit Runtime, no CopilotKit Cloud, no API keys. CopilotKit is used purely as an open-source (MIT) React component library.
- **Endpoint-configurable** (ADR 0005): the AG-UI endpoint URL comes from a Vite env var (`VITE_AGENT_ENDPOINT`, default `http://localhost:7777/agui`). One mechanism for dev and production — no dev-proxy special case.
- **Minimalism is a requirement**: smallest code and architecture that satisfies the goal. No state-management library, no router, no component library beyond CopilotKit's prebuilt chat UI, no test framework in this milestone.
- **Phase-1 visibility** (ADR 0004): single assistant voice; tool calls shown with the built-in generic renderer. No custom cards yet.

Tech stack: Vite + React 19 + TypeScript + CopilotKit React SDK (direct AG-UI) + Tailwind CSS for the page layout. Exact CopilotKit wiring follows the official "connect AG-UI agents" docs at implementation time.

## 3. Scope

### 3.1 In Scope

1. **Project scaffold**
   - Vite `react-ts` project with Tailwind CSS.
   - npm scripts: `dev`, `build`, `preview`, `lint`, `typecheck`.
   - `.env.example` documenting `VITE_AGENT_ENDPOINT` (default `http://localhost:7777/agui`).

2. **AG-UI connection**
   - CopilotKit provider configured with a direct AG-UI agent whose endpoint URL comes from `VITE_AGENT_ENDPOINT`.
   - No CopilotKit Cloud / runtime dependencies, no API keys anywhere.

3. **Chat page (the only page)**
   - CopilotKit prebuilt chat component with its default stylesheet, filling the viewport.
   - Generic tool-call rendering enabled (built-in default tool renderer) so calculator/shell calls are visible with running/done states.
   - Page title and minimal branding text (e.g. "Spectres").

4. **Conversation continuity**
   - Persist the AG-UI `thread_id` in `localStorage`; reuse it on reload so the conversation continues from the Runtime's PostgreSQL session store.
   - A "New conversation" button that resets the thread id.

5. **Documentation**
   - `README.md`: prerequisites (Runtime running on :7777 with CORS configured), `npm install && npm run dev`, MVP run on one PC (`npm run build` + serve `dist/` with any static server), endpoint configuration.

### 3.2 Out of Scope

- Session/thread list UI, thread renaming, multi-thread management.
- Custom tool-call cards (e.g. dispatch cards), generative UI, shared-state usage.
- HITL confirmation UI (no confirmation-gated tools exist in the Runtime yet).
- Authentication, user selection, multi-tenancy.
- PWA, mobile-specific layout, dark mode, i18n.
- Automated tests (deferred; manual verification only in this milestone).
- Deployment beyond one PC (Tailscale, cloud hosting — ADR 0005 phases 2-3).

## 4. Success Criteria

- [x] `npm run dev` opens a working chat against the Runtime on `localhost:7777`, cross-origin, with streaming replies.
- [x] Tool calls (e.g. asking for a calculation) render with the built-in tool renderer.
- [x] Reloading the page continues the same conversation; "New conversation" starts a fresh thread.
- [x] `npm run build` produces a `dist/` that works when served by any static server on the same PC.
- [x] The endpoint URL is configurable via `VITE_AGENT_ENDPOINT` and documented in `.env.example`.
- [x] `npm run lint` and `npm run typecheck` pass.
- [x] `README.md` documents dev and one-PC MVP workflows.
- [x] No secrets or generated artifacts are committed.
